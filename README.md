# Dial Clock – Android live wallpaper

Rotating minute & seconds dial clock with day/date, accent colour, background colour/image and 12/24 h.

## Get the APK (no Android Studio needed)
1. Create a free GitHub account and a new **public or private repository**.
2. Upload all files from this folder (keep the `.github` folder – it builds the APK).
3. Open the repository's **Actions** tab → "Build APK" runs automatically (≈3–5 min).
4. Open the finished run → download **DialClock-apk** (a zip) → unzip → `app-debug.apk`.
5. Copy the APK to your phone, open it, allow "Install unknown apps" when asked.
6. Open **Dial Clock** → customise → **Set as live wallpaper**.
